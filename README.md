# Prueba de carpetas para SS IPTV

Listas de prueba con dos subcarpetas. Los videos se reproducen directamente desde los servidores de JW.ORG. Este repositorio no almacena videos ni es un sitio oficial de JW.ORG.

## Uso

Cuando GitHub Pages esté habilitado desde la rama main y la carpeta raíz, agregar esta lista externa en SS IPTV:

https://walli1912.github.io/jw/inicio.m3u

Las subcarpetas contienen «Un día en la vida de…» y «Las buenas noticias según Jesús».

Prueba estática: aún no hay actualización programada.
